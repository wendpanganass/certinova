# CERTINOVA

Examens blancs **Excel Expert (MO-211)** dans un environnement fidèle au centre d'examen : tableur complet, panneau des tâches, chronomètre, notation automatique, convocations par lien et certificat de réussite.

*Passez du savoir à la reconnaissance internationale !*

- **Candidats** : ouvrez le lien de convocation envoyé par votre formateur, depuis un ordinateur.
- **Formateur** : bouton « Espace formateur » (protégé par un code PIN propre à votre navigateur).

CERTINOVA est un outil de préparation indépendant. Le certificat délivré atteste la réussite d'un examen blanc CERTINOVA et ne constitue pas une certification Microsoft. Les sociétés citées dans les classeurs sont fictives.
